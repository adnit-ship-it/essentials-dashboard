# Section Preview Screenshots

Place section preview images here for the Add Section picker. Structure:

```
section-screenshots/
  {template-name}/     (e.g. serenova-template)
    {section-id}.png   (e.g. home-hero.png, trusted-by.png, cta.png)
```

Supported section IDs (from registry): hero, home-hero, trusted-by, cta, features, marquee, discover, journey, faq, stats, before-after, products, etc.

Images should be aspect-video (16:9) for consistent display in the grid.
